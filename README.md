## Stack

**Backend**

- Node.js / Next.js — APIs y aplicaciones full-stack
- Svelte / SvelteKit — interfaces ligeras y performantes

**DevOps & Infraestructura**
- **Docker Swarm** con Traefik como reverse proxy y balanceador

- GitHub Actions — inyección de secretos y automatización de despliegues
- Azure — Blob Storage y servicios en la nube
- Linux en VPS, gestión de redes y hardening de servidores

**Seguridad**
- Respuesta a incidentes: repelido ataques activos en producción y recuperación de archivos desde S3

- Inyección segura de credenciales en CI/CD via GitHub Actions Secrets
- Hardening de contenedores y superficie de ataque en APIs
